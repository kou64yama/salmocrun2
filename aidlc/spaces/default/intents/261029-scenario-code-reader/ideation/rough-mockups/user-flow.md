# 利用の流れ

入力: [目的](../intent-capture/intent-statement.md)、[範囲](../scope-definition/scope-document.md)、[機能一覧](../scope-definition/intent-backlog.md)、[画面案](wireframes.md)。

1. アプリを開き、端末から画像を選ぶ。
2. プレビューを確認する。選択後に読み取りが自動で始まる。
3. 読み取れたコードを確認し、画像とともに共有する。
4. 同時に共有できない場合は、コードのコピーなどの代替手段を利用する。
5. 読み取れない場合は案内を確認し、別の画像を選ぶ。

## 情報構造

メイン画面に入力、画像、進行状況または結果、共有・代替手段を順に表示する。初回は認識結果の手動修正を含めない。
