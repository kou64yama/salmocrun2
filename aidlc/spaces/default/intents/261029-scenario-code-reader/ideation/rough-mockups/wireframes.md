## メイン画面

一画面に次の順序で配置する。スマートフォンでは縦並び、デスクトップでも読みやすい幅に収める。サーモンランを想起させる雰囲気とする。

1. アプリ名と短い説明
2. 「画像を選択」ボタン
3. 選択した画像のプレビュー
4. 読み取り状況、または読み取ったシナリオコード
5. 「共有」ボタン。共有できない場合はコードをコピーする代替手段

画像選択後に自動で読み取りを開始する。処理中は状態を示し、認識できない場合はその旨を伝え、別の画像を選べるようにする。コードの手動修正は初回範囲外。

アクセシビリティ: アプリ名を h1、結果を h2 とし、header と main を設ける。キーボードの入口は画像選択ボタンとし、状態変化を読み上げ可能にする。
