# プロダクトの目的

## Problem Statement

スプラトゥーン 3 のサーモンラン Next Wave におけるバイトシナリオのコードの手入力や共有にかかる手間を減らす。スクリーンショットからコードを読み取り、画像とコードを共有しやすくする。 [Q1] [Q4]

## Target Customer

シナリオを共有したいサーモンランのプレイヤー。 [Q2]

## Success Metrics

初回リリースでは、対応する画像からコードを読み取り、画像とともに共有できることを成功条件とする。認識精度の数値目標は設けない。 [Q3]

## Initiative Trigger

コードの手入力や共有の手間を減らしたい。 [Q4]

## Initial Scope Signal

- workflow-selected: `mvp`。 [scope]
- 初回リリースは、スプラトゥーン 3 のサーモンラン Next Wave のバイトシナリオを対象とする、ブラウザ内で動作する PWA とし、バックエンドを使わず、Web Share API で画像とコードを共有する。説明された機能以外は対象外とする。 [Q7]

## Assumptions & Open Questions

None.
