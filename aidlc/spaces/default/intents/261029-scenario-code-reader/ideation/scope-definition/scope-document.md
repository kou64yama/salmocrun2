# 初回リリースの範囲

入力: [目的](../intent-capture/intent-statement.md)、[実現可能性](../feasibility/feasibility-assessment.md)、[制約](../feasibility/constraint-register.md)、[範囲の回答](scope-definition-questions.md)。

## 対象

- スプラトゥーン 3 のサーモンラン Next Wave のバイトシナリオ画像からコードを読み取る PWA。
- 端末に保存された、Nintendo Switch で撮影した加工されていないバイトシナリオ画面を選択する。
- 読み取ったコードと画像を Web Share API で共有する。画像とコードを一緒に共有できない場合は、コードのコピーなどの代替手段を用意する。
- ブラウザ内で処理し、バックエンドを使わない。優先環境はスマートフォンとデスクトップの Chrome。
- 初回は認識精度の数値目標を設定しない。

## 対象外

- 共有前のコードの手動修正。
- 初回読み込み後のオフラインでの読み取りの必須対応。
- 説明・確認された機能以外の機能。加工・切り抜き画像への対応は初回対象に含めない。

## 利用の流れ

画像を選択 → コードを読み取る → コードと画像を共有する。共有できない場合は代替手段を使う。

## 未解決事項

対応画像の具体的な検証例、認識失敗時の表示、共有先ごとの挙動は後続で明確化する。機能別の期限はない。
