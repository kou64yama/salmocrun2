# リスク・前提・課題・依存関係

入力: [プロダクトの目的](../intent-capture/intent-statement.md)、[回答](feasibility-questions.md)。

| 種別 | 内容 | 対応 |
| --- | --- | --- |
| リスク | 画像の状態によってコードの認識に失敗する可能性がある。 | 対応画像と検証例を決め、実画像で確認する。精度の数値目標は初回には設けない。 |
| リスク | 利用環境や共有先によって画像とコードを一緒に共有できない可能性がある。 | 利用可否を確認し、コードのコピーなどの代替手段を用意する。 |
| 課題 | 対応画像の条件と検証例が未決定。 | 要件整理で決定する。 |
| 課題 | 必要な資源の取得とオフライン利用範囲が未決定。 | 後続の設計で確認する。 |
| 依存 | ブラウザと OS の共有機能およびユーザーが選ぶ共有先。 | 優先環境で実際に確認する。 |

前提: 優先環境の Chrome で機能が利用できることは、実機検証まで確定しない。
