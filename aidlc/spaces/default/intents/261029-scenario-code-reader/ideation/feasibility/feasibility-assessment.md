# 実現可能性の評価

入力: [プロダクトの目的](../intent-capture/intent-statement.md)、[回答](feasibility-questions.md)。

## 評価

ブラウザ内の画像認識と共有を組み合わせる方針は検討可能だが、実際の画像での認識と対象環境での共有は未検証。初回の認識精度目標は設けず、対応画像の条件と検証例を後続で決める。

Web Share API は安全なコンテキストとユーザー操作を必要とし、ファイル共有の可否は環境に依存する。[MDN: Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Share_API) 画像とコードを同時に共有できない場合は、コードのコピーなどの代替手段を用意する。実機での確認が必要。

## 不確実性

- 画像の種類、画質、レイアウトによる認識結果は未検証。
- 端末や共有先によって画像とコードが意図どおり渡るかは未検証。
- ブラウザ内処理に必要な資源の配布・取得条件やオフライン動作の範囲は未決定。
