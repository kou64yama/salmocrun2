# 操作仕様

入力: [ラフ案](../../ideation/rough-mockups/wireframes.md)、[利用の流れ](../../ideation/rough-mockups/user-flow.md)、[ストーリー](../user-stories/stories.md)、[要件](../requirements-analysis/requirements.md)、[開発方針](../practices-discovery/team-practices.md)。

## 画像選択

選択後にプレビューを更新して自動で読み取りを開始する。選び直しは読み取り中も可能。新しい画像の選択時に以前の結果と共有操作をクリアし、新しい画像の処理を開始する。先行する読み取りが後から完了しても、その結果は破棄し、表示・共有しない。選択をキャンセルした場合は現在の状態を保持する。

## 状態と結果

読み取り中は進行状態を表示し、共有・コピーを利用不可にする。結果がある場合はコードと操作を表示する。形式不一致は警告を添える。文字がない場合は失敗を表示し選び直せる。状態変化は読み上げに伝える。

## 共有・コピー

共有可能な場合はユーザーの操作で画像とコードを共有する。キャンセルは通常の結果画面に戻す。共有不可の場合はコードのコピーを提供する。共有・コピーの失敗は具体的に通知し、結果を保持して再試行可能にする。

## 入力と応答

操作はキーボードで到達・実行でき、フォーカスを視認できる。状態は色だけで区別せず、ラベルと説明を用いる。狭い画面でも横スクロールなしに操作できるよう幅を調整する。
