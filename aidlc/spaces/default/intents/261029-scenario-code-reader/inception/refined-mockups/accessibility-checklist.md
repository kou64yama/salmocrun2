# アクセシビリティの確認項目

入力: [ラフ案](../../ideation/rough-mockups/wireframes.md)、[利用の流れ](../../ideation/rough-mockups/user-flow.md)、[ストーリー](../user-stories/stories.md)、[要件](../requirements-analysis/requirements.md)、[開発方針](../practices-discovery/team-practices.md)。目標は WCAG 2.2 AA。現時点では未検証。

- [ ] 画像選択、共有、コピーをキーボードだけで操作でき、フォーカスが見える。
- [ ] 操作名、画像の説明、読み取り中・結果・失敗を読み上げで把握できる。
- [ ] 文字、操作部品、フォーカスのコントラストを確認する。
- [ ] 警告と失敗を色だけで示さない。
- [ ] 拡大表示と狭い画面で情報と操作が失われない。
- [ ] 自動検査と手動操作・読み上げ確認を行い、未確認の達成基準を記録する。

## 達成基準ごとの記録

WCAG 2.2 AA の適用可能な各達成基準について、対象画面・状態、確認方法（自動・手動・読み上げ等）、結果（適合・不適合・未確認・対象外）、証拠と確認環境、対象外の理由または未確認の理由を記録する。不適合は修正後に再確認する。チェック項目の実施だけをもって全基準への適合を主張しない。
