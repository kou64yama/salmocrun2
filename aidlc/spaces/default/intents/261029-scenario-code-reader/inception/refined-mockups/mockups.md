# 画面の詳細案

入力: [ラフ案](../../ideation/rough-mockups/wireframes.md)、[利用の流れ](../../ideation/rough-mockups/user-flow.md)、[ストーリー](../user-stories/stories.md)、[要件](../requirements-analysis/requirements.md)、[開発方針](../practices-discovery/team-practices.md)。

## メイン画面

暗い背景、暖色のアクセント、読みやすい明るい文字を用い、サーモンランを想起させる。スマートフォンは一列、デスクトップは幅を制限した中央の一列で表示する。

1. 見出し「シナリオコードを読み取る」と短い説明。
2. 主操作「画像を選択」。対象は加工していないバイトシナリオ画面。
3. 選択画像のプレビューと「別の画像を選択」。
4. 状態領域: 「読み取り中」、コード、形式不一致の警告、または読み取り失敗。
5. 結果があるとき「共有」。画像とコードを一緒に共有できない場合は「コードをコピー」を提示する。

## 配置イメージ

### スマートフォン

```text
+--------------------------+
| SCENARIO CODE            |
| Select a screenshot      |
|                          |
| [ Select image         ] |
|                          |
| +----------------------+ |
| |   Image preview      | |
| |                      | |
| +----------------------+ |
|                          |
| +----------------------+ |
| | Result or status     | |
| +----------------------+ |
| [ Share                ] |
| [ Select another image ] |
+--------------------------+
```

### デスクトップ

```text
+------------------------------------------------------+
|                                                      |
|        +------------------------------------+        |
|        | SCENARIO CODE                      |        |
|        | Select a screenshot                |        |
|        | [ Select image                   ] |        |
|        | +--------------------------------+ |        |
|        | |         Image preview          | |        |
|        | +--------------------------------+ |        |
|        | +--------------------------------+ |        |
|        | | Result or status               | |        |
|        | +--------------------------------+ |        |
|        | [ Share ] [ Select another image ] |        |
|        +------------------------------------+        |
|                                                      |
+------------------------------------------------------+
```

図中の英語は配置を示す仮ラベルで、実際の画面は日本語とする。

### 状態領域の見え方

```text
Reading:   [ Reading...                  ]
Result:    [ S123-4567-89AB-CDEF         ]
Warning:   [ Check the code format       ]
Failure:   [ Could not read the code     ]
           [ Select another image        ]
```

読み取り中は共有・コピーを利用不可にし、結果には共有、形式不一致には警告、失敗には選び直しを表示する。幅は図の比率に固定せず、狭い画面に合わせて調整する。

スマートフォンでは画面左右に約 16px の余白を置き、幅いっぱいの画像選択ボタン、画像プレビュー、状態カード、操作ボタンを縦に並べる。デスクトップでは最大幅約 720px の中央カラムとし、左右に余白を取る。プレビューは元画像の縦横比を維持し、画面幅を超えない。

| 状態 | 表示内容 | 操作 |
| --- | --- | --- |
| 初期 | 見出し、説明、画像選択 | 画像を選択 |
| 読み取り中 | プレビュー、進行表示「読み取り中」 | 別の画像を選択。共有とコピーは利用不可 |
| 結果 | プレビュー、コード、必要な場合は形式不一致の警告 | 共有、または共有不可時にコピー。画像を選び直せる |
| 失敗 | プレビュー、「コードを読み取れませんでした」 | 別の画像を選択 |
| 共有・コピー失敗 | 結果を保持し、失敗の説明を表示 | 同じ操作を再試行 |

## 状態

初期状態では画像選択を表示し、結果と共有は表示しない。選択後は画像と読み取り中の状態を表示する。完了後はコードを表示し共有できる。形式不一致なら警告し、確認操作なしで候補を共有できる。文字が得られない場合は失敗を知らせ、別の画像を選べる。

共有をキャンセルした場合はエラーを出さず結果に戻る。共有またはコピーの失敗時は結果を保持し、失敗を知らせて再試行できる。
