# ユーザーストーリー

入力: [要件](../requirements-analysis/requirements.md)、[開発方針](../practices-discovery/team-practices.md)、[利用者像](personas.md)。すべて Must Have。各ストーリーは単独で受け入れ条件を検証できるように分ける。

## US1.1 画像からコードを読み取る

プレイヤーとして、保存した画像を選んでコードを読み取りたい。手入力の手間を減らすため。依存: なし。

- **AC1.1.1** Given 保存した対象画像があるとき、When 画像を選択すると、Then プレビューが表示され自動で読み取りが始まる。
- **AC1.1.2** Given 読み取り中、When 処理が続いていると、Then 読み取り中の状態が表示される。
- **AC1.1.3** Given コードが読み取れたとき、When 処理が完了すると、Then ゲーム画面の区切りと大文字・小文字で結果を表示する。
- **AC1.1.4** Given 文字がまったく読み取れない画像、When 処理が完了すると、Then 失敗を知らせ、別の画像を選べる。
- **AC1.1.5** Given 読み取った結果が指定の正規表現に一致しないとき、When 結果が表示されると、Then 形式不一致を知らせ、候補を表示する。
- **AC1.1.6** Given 画像を読み取りアプリを閉じた後、When ブラウザのアプリ領域の永続ストレージを確認すると、Then 選択画像と読み取ったコードが履歴として保存されておらず、再度開いても表示されない。

## US1.2 コードと画像を共有する

プレイヤーとして、読み取ったコードと画像を共有したい。ほかのプレイヤーにシナリオを伝えるため。依存: US1.1 の読み取り結果と画像。

- **AC1.2.1** Given コードと画像を共有できる環境、When 共有を選ぶと、Then Web Share API にコードと画像を渡す。
- **AC1.2.2** Given 形式不一致の候補、When 共有を選ぶと、Then 警告された候補も共有できる。
- **AC1.2.3** Given 画像とコードを一緒に共有できない環境、When 代替手段を使うと、Then コードをコピーできる。

## US1.3 アプリとして使う

プレイヤーとして、PWA を端末にインストールしたい。ホーム画面やアプリ一覧から起動するため。依存: なし。

- **AC1.3.1** Given 優先対象の Chrome 環境、When PWA をインストールすると、Then ホーム画面またはアプリ一覧から起動できる。
- **AC1.3.2** Given スマートフォンまたはデスクトップの Chrome、When アプリを開くと、Then 画像選択、プレビュー、結果、共有が日本語の一画面に順に表示される。
- **AC1.3.3** Given キーボードと読み上げを使うとき、When 画像選択、共有、コピーを操作すると、Then キーボードで各操作に到達して実行でき、読み上げで操作名を確認できる。読み取り中、結果、失敗の状態も読み上げで確認できる。
- **AC1.3.4** Given 画像を読み取るとき、When アプリを利用すると、Then 読み取りはブラウザ内で行われ、バックエンドを使用しない。

## 検証上の注意

初回は認識精度と読み取り時間の数値目標を設けない。共有のキャンセル・失敗とコピー失敗の詳細は後続の設計で具体化する。
