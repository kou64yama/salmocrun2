# 要件

入力: [目的](../../ideation/intent-capture/intent-statement.md)、[範囲](../../ideation/scope-definition/scope-document.md)、[開発方針](../practices-discovery/team-practices.md)、[回答](requirements-analysis-questions.md)。

## 目的

サーモンラン Next Wave のバイトシナリオコードの手入力と共有の手間を減らす。

## 機能要件

- **FR1** 端末に保存された画像を選択できる。対象は Nintendo Switch で撮影した加工されていないバイトシナリオ画面とする。
- **FR2** 選択した画像をプレビューし、選択後に自動で読み取りを開始する。
- **FR3** 読み取り中であることを表示する。
- **FR4** 読み取ったコードを表示し、ゲーム画面の区切りと大文字・小文字の表記を再現する。コード形式は `^S[0-9A-HJ-NP-Z]{3}-[0-9A-HJ-NP-Z]{4}-[0-9A-HJ-NP-Z]{4}-[0-9A-HJ-NP-Z]{4}$` とする。
- **FR5** 文字をまったく読み取れなかった場合は失敗を知らせ、別の画像を選べるようにする。文字が得られない画像を用いて確認する。
- **FR10** 読み取り結果が指定の形式に一致しない場合、形式が一致しないことを知らせ、候補として表示し共有できるようにする。
- **FR6** 読み取ったコードと選択画像を Web Share API で共有できるようにする。
- **FR7** 画像とコードを同時に共有できない場合は、コードをコピーできる代替手段を用意する。
- **FR8** 初回の画面表示は日本語とする。
- **FR9** 画像選択、プレビュー、結果、共有を一画面に順に表示する。

## 非機能要件

- **NFR1** 読み取りはブラウザ内で行い、バックエンドを使用しない。
- **NFR2** スマートフォンとデスクトップの Chrome を優先対象とする。
- **NFR3** 画像とコードはアプリを閉じた後にアプリの履歴として保存しない。
- **NFR4** 基本的な操作をキーボードで行え、操作対象と読み取り状態を読み上げで把握できる。
- **NFR5** PWA としてインストールできる。優先対象の Chrome 環境でインストールし、ホーム画面やアプリ一覧から起動できることを確認する。

## 制約

Vite、React、React Router、Mantine UI、Tesseract.js、Vitest、testing-library、Playwright を使用する。テスト先行、行カバレッジ 80% 以上、マージ前 CI を開発方針とする。

## 対象外

共有前のコードの手動修正、加工・切り抜き画像への対応、初回読み込み後のオフラインでの読み取りの必須対応。初回の認識精度および読み取り時間に数値目標は設けない。

## 前提と未決事項

- 正解コードが分かる実スクリーンショットを用意できる。具体的な画像と検証方法は後続で確定する。
- 共有キャンセル時の扱いは詳細設計で確認する。
