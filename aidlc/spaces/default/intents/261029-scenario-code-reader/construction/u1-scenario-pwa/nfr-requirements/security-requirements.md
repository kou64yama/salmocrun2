# セキュリティとデータの取り扱い

入力: [機能仕様](../functional-design/functional-spec.md)、[要件](../../../inception/requirements-analysis/requirements.md)、[回答](nfr-requirements-questions.md)。

- **NFR1.1** 認識はブラウザ内で行い、バックエンドを使わない。利用者が共有を選ぶ場合を除き、画像と認識結果を外部へ送信しない。認識用プログラム・データの取得は別に扱う。通信内容を検証する。
- **NFR3.1** 画像と結果を履歴として永続ストレージに保存しない。読み取り後とアプリを閉じた後の保存領域を検証する。
- JPEG 以外や読み込めない入力は処理せず通知する。認識データの取得元と依存関係を設計時に確認する。
