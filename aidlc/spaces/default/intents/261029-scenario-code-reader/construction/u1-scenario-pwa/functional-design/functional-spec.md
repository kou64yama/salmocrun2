# 機能仕様: u1-scenario-pwa

入力: [作業単位](../../../inception/units-generation/unit-of-work.md)、[割り当て](../../../inception/units-generation/unit-of-work-story-map.md)、[ストーリー](../../../inception/user-stories/stories.md) US1.1、US1.2、US1.3、[要件](../../../inception/requirements-analysis/requirements.md)、[構成](../../../inception/domain-design/components.md)、[回答](functional-design-questions.md)。

## 状態とデータ

選択操作ごとの識別子、JPEG 画像、表示用プレビュー、状態、読み取り候補と形式判定を一時的に保持する。画像とコードは履歴として永続保存しない。新しい選択では識別子を更新し、古い完了を無視する。

## 画像選択と読み取り

1. 初期状態で画像選択を表示する。JPEG 以外や読み込めないファイルは通知し、選び直せる。選択キャンセルは現状態を保持する。
2. 新しい JPEG の選択時、古い結果をクリアし、プレビューを表示して読み取りを開始する。共有・コピーは無効。
3. 対象画面のコード領域を切り出し、文字を認識する。領域の初期候補と実画像は構成文書に記載する。読み取りの準備失敗や処理失敗を通知し、同じ画像で再試行できる。
4. 結果の前後の空白・改行を除く。空なら失敗を表示し、再試行または選び直しを可能にする。
5. 空でない候補を `^S[0-9A-HJ-NP-Z]{3}-[0-9A-HJ-NP-Z]{4}-[0-9A-HJ-NP-Z]{4}-[0-9A-HJ-NP-Z]{4}$` で判定する。一致しなければ警告を添えるが共有可能。一致は正確性を保証しない。
6. 途中で新画像を選んだ場合、以前の処理が後から完了しても表示・共有しない。読み取り中と結果・失敗を画面と読み上げで伝える。

## 共有とコピー

ユーザー操作により、画像と候補を一緒に共有する。対応しない環境では候補のコピーを提示する。共有のキャンセルはエラーを出さず結果に戻る。共有またはコピー失敗時は結果を維持して失敗を表示し、再試行可能にする。

## 状態遷移

初期 → 読み取り中 → 結果（形式一致または警告）／失敗。結果・失敗から再選択で読み取り中へ、失敗から再試行で読み取り中へ戻る。共有・コピーの完了、キャンセル、失敗後は結果を保持する。新しい選択は以前の処理の識別子を無効にする。

## 導入と利用

日本語の一画面で画像選択、プレビュー、状態、結果と共有を順に表示する。スマートフォンとデスクトップの Chrome を優先し、PWA としてインストール後にホーム画面またはアプリ一覧から起動できることを確認する。読み取りはブラウザ内で実施する。
